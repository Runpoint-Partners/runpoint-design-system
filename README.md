# Runpoint design system

The design tokens and rules behind [runpoint.ai](https://runpoint.ai) and Runpoint OS.

- `DESIGN.md` — principles, type, color, layout and content rules
- `tokens.json` — tokens as data
- `tokens.css` — tokens as CSS custom properties
- `index.html` — a visual reference sheet; open it in a browser

Type: Newsreader, Hanken Grotesk, Geist Mono. Color: paper and ink, with one orange (#FF4400) mark per view. Corners are square.
