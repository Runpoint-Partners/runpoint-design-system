07 · Rules

How to use it

  1. Change a value in design/tokens.json, then run npm run design:build. Never type a hex code or pixel font size into a component.
  2. One orange mark per view.
  3. Bands alternate paper, mist and night. A page usually has one night band.
  4. Square corners. No shadows on panels.
  5. Product screens keep the colors of the client brand they show. They are left out of the audit.
  6. Rebuilt product screens keep the product's own fonts (.rp-os) so they match the captures.
